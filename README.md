## 📊 Features

- ✅ Dashboard with KPI cards
- ✅ View all voters
- ✅ Search and filter
- ✅ Add, edit, delete voters
- ✅ Export to CSV
- ✅ Mobile door-to-door mode
- ✅ Real-time updates
- ✅ Supabase database integration

## 🛠️ Technologies

- GitHub Pages (Hosting)
- Supabase (Database + Auth)
- Vanilla JavaScript
- HTML + CSS
